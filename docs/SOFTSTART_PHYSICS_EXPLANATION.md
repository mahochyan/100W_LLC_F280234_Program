# SOFTSTART_PHYSICS_EXPLANATION — 为什么 250k 冷启动比 150k 更稳

> 任务：OFFBENCH_LLC_VIRTUAL_BOARD_CHARACTERIZATION_V1（H 节）
> 方法：FHA 模型（tools/llc_virtual_plant.py），24V 输入，空载/5W 轻载
> 结论性质：PREDICTED_BY_MODEL（结合实板观察的物理解释）

## 1. 实板观察（回顾，CONFIRMED_BY_HARDWARE）

- 150kHz 直接冷启动曾撞原边 OCP（bring-up 早期记录）；250kHz/DB110 起步 + 斜坡在 STAGE5 正式 SoftStart 中稳定通过（实板 10V 验收 PASS）
- 250k/DB110 空载可维持 11.14V（CAL_HOLD）；150k 爬升到 10.02V 用时 82 个 FINAL 周期

## 2. 模型计算（24V，标称参数 fr=49.9kHz）

## 3. 物理解释链

1. **tank 阻抗随频率↑而↑**（高频段 Zin ≈ ωLr − 1/(ωCr) → ωLr 主导）：250k 时 |Zin|=32Ω，150k 时仅 19Ω → **同样 Vin 下高频电流更小**（0.67A vs 1.13A，空载）。
2. **冷启动第一周期是纯电感冲击**（analysis/llc_first_cycle_model_v1.md）：di/dt = Vin/Lr = 24/3.385µ = **7.09 A/µs**——150k 的 6.67µs 周期内电流可冲至 ~47A（理想电感上界）；250k 的 4µs 周期 ~28A——**高频把每个周期的电流注入量按比例压缩**。
3. **大死区 DB110 进一步限流**：110 ticks = 1.83µs 死区占 250k 周期的 46%——有效导通窗口短，每周期注入能量少；FHA 假设 50% 占空比，实际 DB110 时有效基波更低 → 实际电流比 FHA 更小。
4. **增益差别小、电流差别大**：M(250k)=0.841 vs M(150k)=0.851——增益只差 1%，但**电流差 40%**（0.67 vs 1.13A）→ 冷启动 OCP 风险主要由**电流**驱动，而非增益。
5. **斜坡的平滑性**：250k 起步 → DB 逐级降到 36 → 频率逐级降到 150k，每步 10 周期——tank 电流逐步增长（0.67→1.24A），给 Cr 充电建立电压，避免第一周期大冲击。

## 4. 结论

```
150k 直接冷启动更容易撞 OCP 的原因：
  tank 阻抗低（19Ω vs 32Ω）→ 首周期电流冲击大（~1.7×）
  加上输出电容初始短路等效 → 电流应力集中在首几个周期

250k/DB110 更稳的原因：
  tank 阻抗高 → 电流小 40%
  DB110 死区 46% → 每周期注入能量再减半
  斜坡分步 → 电流平滑建立
```

**250k 起步是"用高频高阻抗 + 大死区限流"换取首周期电流可控**——PREDICTED_BY_MODEL，与实板观察一致（CONFIRMED_BY_HARDWARE 的趋势）。

## 5. 边界与风险

- 以上为空载/轻载 FHA；带载（5W 以上）时 250k 的 M 略降但电流仍最小（表中 5W 列）
- 实板 OCP 为 DAC300 理论 9.67A——模型空载电流（<1.3A）远低于该值，但**首周期瞬态**（时域模型，非 FHA）可超（analysis v1 最坏 39A 上界）——因此 DB110 的限流作用在首周期尤为重要
- 最终 250k 起步的必要性判定仍需实板：回工位后在 150k 直接冷启动对比 OCP 行为（RETURN_TO_BENCH 计划项）
