> 只列**真正不能远程模拟/必须实板**的项目；每项标注虚拟结论（供对照）。

## 按风险排序（必须先做）

| # | 项目 | 为什么必须实板 | 虚拟结论（本次） | 风险等级 |
|---|---|---|---|---|
| 1 | **PFM 方向 150/170k 实板确认** | 唯一能裁决斜率方向与量级的实测；模型两情景差异 4~11% | THEORETICAL=NORMAL，差异边界 | 高（决定控制符号） |
| 2 | **Vgs/Vds ZVS 确认** | 理论 LIKELY 但 Coss ASSUMED；容性区风险真实存在 | LIKELY_ZVS（Coss≤2nF 假设）| 高（损耗/可靠性） |
| 3 | **MOS Vds 尖峰（36V 输入）** | 40V 器件 36V 输入裕量仅 ~4V；必须示波器测 | 裕量极小 ⚠️ | **最高（硬件风险）** |
| 4 | **OCP 安培标定** | CT 变比/R32/整流链路需注入电流实测 | DAC300 理论 9.67A | 高（保护可信度） |
| 5 | **原边谐振电流波形** | 模型电流估计（RMS 7.7~16A 情景依赖）需波形验证 | 见 SEMICONDUCTOR_STRESS | 中 |
| 6 | **Cr 实际装机组合 / LCR 实测** | 决定有效 fr（50k vs 150k 之争）——**最优先的参数澄清** | fr 50k(标称)/150k(情景B) | 高（模型校准） |
| 7 | **输出电压纹波** | 模型无法评估 | 需实测 | 中 |
| 8 | **MOS / 整流 / 变压器 / Lr 温升** | 无 datasheet Rth/Vf → 温升只能实测 | 应力估计见文档 | 中（100W 满载才显著） |
| 9 | **25/50/75/100W 带载** | 满载原边电流可能撞理论 OCP（模型显示 100W 区 Ip 超 9.67A）| OCP 受限案例 | 中高 |
| 10 | **24/30/36V 输入验证** | 24V/12V 需容性区（ZVS 风险）——需实测是否可运行 | 24V 12V 需 M>1（容性区）| 高（设计边界） |
| 11 | **轻载（<5W / 空载）** | 36V 轻载过压需实测 | 模型：空载 36V M>0.88 即超 12V | 中 |

## 建议执行顺序（一次工位会话）

```
安全重启 → 危险条目前置：
  A. 36V 输入 MOS Vds 尖峰测量（低压/轻载起步，最优先）
  B. LCR 实测 Lr/Cr/Lm/匝比（模型校准）
  C. OCP 注入电流标定（DAC300 实际安培）
然后：
  D. PFM 方向 150k/170k 两枪（已完成冷启动熟悉度）-> 校准模型斜率
  E. 轻载/空载 36V 过压行为
  F. 25/50W 带载 12V 调节（若方向确认）
  G. 75/100W 满载电流/温升/OCP 裕量
  H. Vgs/Vds ZVS 波形（150-250k 选点）
```

## 每项 PASS 判据建议

1. PFM 方向：slope_150 vs slope_170 差异 ≥10% 且方向 = 模型方向（否则 MODEL_DIRECTION_MISMATCH）
2. MOS Vds：36V 输入尖峰 ≤ 36×1.3 ≈ 47V（40V 器件裕量不足——**若超 40V 属超标需重新选型/加钳位**）
3. ZVS：Vgs 低电平前 Vds 已到 0（半桥中点）
4. OCP：DAC300 实际触发电流记录（若 ≠9.67A 记录实际值）
5. 带载 12V：25W 内 LLC 调整率可接受；100W 关注 OCP 裕量
