# TRANSFORMER_GAIN_AUDIT — 变压器与增益审计

> 任务：OFFBENCH_LLC_VIRTUAL_BOARD_CHARACTERIZATION_V1（G 节）
> 匝比：Np=5T : Ns_half=4T → n=1.25 [SCHEMATIC]（开发日记/analysis）
> 整流管压降：Vf=0.7V [ASSUMED]

## 1. 理想变压器增益需求

LLC tank 所需增益（达到 12V 输出）：

```
M_req = (Vout + Vf) × 2n / Vin = (12 + 0.7) × 2.5 / Vin
```

| Vin | M_req | 相对 fr 谐振点 (M=1) | 需要的频率区 |
|---|---|---|---|
| 24V | **1.323** | 需 M>1（< fr，容性区或接近谐振） | ⚠️ 24V 下 12V 需要升压增益 |
| 30V | **1.058** | 略高于 1（略低于 fr） | 临界（fr 附近或略低于） |
| 36V | **0.882** | M<1（> fr，感性区） | 高频区可行 ✓ |

## 2. 变比合理性评估

- n=1.25 的设计意图：**30V 输入、12V 输出、谐振点 M=1** → Vout = 30/(2×1.25) = 12V ✓ 匹配 nominal
- 24V：**偏降压方向不足**（需要 M=1.32 升压增益，LLC 在感性区给不出）→ 24V 下 12V 输出需要容性区/近谐振工作，**有 ZVS 丢失风险**
- 36V：**偏升压方向有余**（M=0.88 即可，高频压住输出）→ 36V 下 12V 容易

**结论**：
1. 当前变比相对 30V nominal **合理**（谐振点即 12V）
2. 相对 24V 输入 **偏降压**（需要 tank 升压增益 M=1.32）
3. 相对 36V 输入 **偏升压**（tank 需降压 M=0.88，容易满足）
4. **24V 输入时需要最大 tank 增益（M=1.32）**；36V 输入 + 轻载时需要最高频率压住输出（模型：36V 轻载 12V 需 f≈88kHz；若负载更轻 → 频率更高，见下）

## 3. 36V 轻载高频需求检查（重点）

模型（标称 fr=49.9kHz）36V 12V 目标工作频率：

| Pout | f_work（感性区解） |
|---|---|
| 5W | 88.1kHz |
| 25W | 82.1kHz |
| 50W | 74.5kHz |
| 75W | 69.5kHz |
| 100W | 66.1kHz |

- 36V 下 12V 需要 **66~88kHz**（标称参数）——**远低于 150k/170k 测试区**；若用 150k+ 则 Vout < 12V（24V 时 150k 只有 ~10V——与实板一致！）
- 36V + 更轻负载（<5W 或空载）：f_work → 趋近 fr 或略高于（~90-120kHz 量级）——**不需要极高频率压住输出**（因为 M_req=0.88 只需略高于 fr 即可），但空载时若频率不够高，Vout 会超 12V（M>0.88）——**空载 36V 时需注意输出过压**（固件 OVP/硬顶保护已就位，虚拟闭环矩阵覆盖此场景）
- ⚠️ 若有效 fr 实为 150kHz（情景 B，Cr≈0.33µF），则 36V/12V 需要 **f<150k（容性区）**——模型参数不确定性的直接后果；实板两枪（24V）只能校准 24V 点，36V 行为仍 [REQUIRES_BENCH]

## 4. 实板数据交叉检查

- 实板 24V/150k 达 10.02V → M_eff = 2.5×10.02/24 = 1.044——标称模型（fr=50k）在 150k 给 M=0.85（→8.2V），**不符**；情景 B（fr=150k）给 M=1.00（→9.6V），接近
- 实板 250k/DB110 空载 11.14V → M_eff=1.16——两种情景都给不出（FHA 空载 250k：0.84/0.89）——**差异指向：匝比或 DB110 有效占空比或 Cr 预充的非 FHA 效应**

**审计裁决**：n=1.25 维持为标称；模型-实板系统性偏差（~20-30%）在总报告中标记为 `MODEL_VS_HARDWARE_DEVIATION`，由实板 150/170k 两枪斜率校准（REMOTE_BENCH §15：不一致 → MODEL_DIRECTION_MISMATCH 检查项）。
